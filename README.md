# Copella Recorder - Girly Edition

Интернет-радио с записью эфира в стиле Girly.

## Особенности

- 🎵 **Интернет-радио** - прослушивание радиостанций онлайн
- 🎙️ **Запись эфира** - сохранение передач в MP3
- 📅 **Планировщик** - автоматическая запись по расписанию
- 🎨 **Girly дизайн** - женственный стиль с фиолетово-розовыми акцентами
- ✨ **Микрофункции** - блестки, градиенты, эффекты ripple
- 📱 **Адаптивность** - работает на всех устройствах

## Установка

1. Загрузите `copella-recorder-girly-v1.0-final.zip`
2. Установите через админ-панель WordPress
3. Активируйте плагин
4. Используйте шорткод `[copella_recorder]`

## Шорткоды

```
[copella_recorder]
```

## Требования

- WordPress 5.0+
- Современный браузер
- Поддержка HTML5 Audio API

## Поддержка

Плагин использует:
- Tailwind CSS для стилизации
- HLS.js для потокового аудио
- LameJS для кодирования MP3
- Gilroy шрифт для типографики
