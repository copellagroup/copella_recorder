# Custom Sidebar Plugin - Модифицированная версия

## Описание

Модифицированная версия плагина Custom Sidebar Plugin, которая автоматически определяет страницу `copella.live/copella-recorder` и показывает специальный хедер вместо обычного.

## Новые возможности

- **Автоматическое определение страницы**: Плагин автоматически определяет, когда пользователь находится на странице copella-recorder
- **Специальный хедер**: На странице copella-recorder отображается специальный хедер с кнопкой "Назад", логотипом и кнопкой настроек
- **Совместимость**: Полная совместимость с существующим функционалом плагина

## Установка

1. Распакуйте архив `custom-sidebar-plugin-modified.zip`
2. Загрузите папку `custom-sidebar-plugin` в директорию `/wp-content/plugins/`
3. Активируйте плагин в админ-панели WordPress

## Файлы

### Новые файлы:
- `nextgen/header-template-recorder.php` - Шаблон специального хедера
- `nextgen/header-recorder.css` - Стили для специального хедера  
- `nextgen/header-recorder.js` - JavaScript для специального хедера

### Модифицированные файлы:
- `new-sidebar.php` - Основной файл плагина с логикой определения страницы

## Логика работы

Плагин определяет страницу copella-recorder по следующим критериям:

1. **URL**: Проверяет наличие `/copella-recorder` в URL
2. **Slug страницы**: Проверяет slug страницы на равенство `copella-recorder`
3. **Шорткод**: Проверяет наличие шорткода `[copella_recorder]` в контенте страницы
4. **JavaScript проверка**: Дополнительная проверка на клиенте

## Специальный хедер

Специальный хедер включает:

- **Кнопка "Назад"**: Возвращает пользователя на предыдущую страницу или на главную
- **Логотип Copella**: Центральное расположение с адаптивным размером
- **Кнопка настроек**: Открывает модальное окно настроек приложения
- **Время**: Отображение московского времени (если включено)

## Стили

Специальный хедер использует:
- Темную цветовую схему (#0A0A0A)
- Шрифт Manrope
- Адаптивный дизайн
- Плавные переходы и анимации

## Совместимость

- WordPress 5.0+
- PHP 7.4+
- Современные браузеры с поддержкой CSS Grid и Flexbox
