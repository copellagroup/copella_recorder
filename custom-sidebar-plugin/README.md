# Custom Sidebar Plugin - Упрощенная версия

## Описание

Упрощенная версия плагина Custom Sidebar Plugin, которая автоматически скрывает обычный хедер на странице `copella.live/copella-recorder`, позволяя использовать собственный хедер из плагина copella-recorder.

## Новые возможности

- **Автоматическое скрытие хедера**: Плагин автоматически скрывает обычный хедер на странице copella-recorder
- **Сохранение функциональности**: Все остальные функции плагина работают как обычно
- **Простота**: Минимальные изменения в коде для максимальной совместимости

## Установка

1. Распакуйте архив `custom-sidebar-plugin-simple.zip`
2. Загрузите папку `custom-sidebar-plugin` в директорию `/wp-content/plugins/`
3. Активируйте плагин в админ-панели WordPress

## Логика работы

Плагин определяет страницу copella-recorder по следующим критериям:

1. **URL**: Проверяет наличие `/copella-recorder` в URL
2. **Slug страницы**: Проверяет slug страницы на равенство `copella-recorder`
3. **Шорткод**: Проверяет наличие шорткода `[copella_recorder]` в контенте страницы

При обнаружении страницы copella-recorder:
- Обычный хедер не загружается (CSS и JS)
- Обычный хедер не рендерится
- Сайдбар продолжает работать как обычно

## Совместимость

- WordPress 5.0+
- PHP 7.4+
- Современные браузеры с поддержкой CSS Grid и Flexbox
